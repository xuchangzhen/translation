# 桌面端 0.9.0 / Android 单词记忆 0.4.0

本次需要同时更新电脑和手机：电脑端增加 AI 中转站翻译配置，手机端增加自定义词库导入与加密同步。词库同步服务器与 AI 翻译中转站是两个独立服务。

## 电脑端（macOS / Windows）

- 设置中选择“AI 中转站（OpenAI 兼容）”，填写 Base URL、API Key、Model 后即可用于翻译和技术解析，支持获取模型、手动填写模型和测试连接。
- Google、OpenAI、AI 中转站分别保存加密密钥；升级迁移旧配置，切换服务不会互相覆盖密钥。
- 兼容接口仅在服务明确拒绝扩展参数时重试基础请求，并改善地址校验与错误提示。
- 调整音标重音符号显示。

## Android 0.4.0（versionCode 5）

- 导入 CSV、TSV、TXT、JSON，自定义词库单独管理，支持预览与按词库复习。
- 支持 UTF-8、带 BOM 的 UTF-16 自动识别；编码不匹配时可选择 GB18030、UTF-16LE/BE 重试。上限 64 MB / 100,000 条。
- 数据库从 v1/v2 迁移到 v3，保留旧词条 ID、复习状态和历史记录；同一单词可存在于不同词库。
- 用户主动同步的词库以密文快照上传；同一同步空间的其他 Android 下载解密，复习进度仍保存在各设备本地。
- 本地内容与云端发生冲突时保留本地副本；已下载版本不反复下载；大词库按字节分片上传。
- 更新应用图标和音标显示。

## 更新方式

电脑在设置中检查更新。手机由同步服务器镜像 GitHub Release 的签名 APK 和 `latest-android.json` 后，在应用内“立即检查更新”，下载完成后点击安装通知。服务器镜像和手机自动检查各有约六小时周期，发布后不会即时向所有手机推送。

使用原有 APK 签名覆盖升级即可，不需要卸载、删除数据或重新配对。AI 中转站账号可以更新后在电脑端自行配置。

## 验证边界

本地桌面 89 项测试、Electron safeStorage/API 运行检查通过；Android 24 项测试、Lint 和签名 APK 构建通过。发布工作流在 macOS、Windows 和 Linux Android 构建机重新验证并构建；原有真实 AI 中转账号连接由用户配置后验收。服务器数据库和真实密文接口已单独完成部署验收。
