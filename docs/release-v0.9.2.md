# 同步空间与学习体验更新

Android 单词记忆 `0.4.2`（`versionCode=7`）和桌面端 `0.9.2` 调整了同步与学习流程：

- 创建同步空间只需要同步服务器地址；桌面端、Android 客户端和中继服务都不再使用服务器注册码。
- 桌面端将“加入已有空间”和“首次创建空间”并列展示，并给出从已连接电脑发送一次性链接的两步说明。
- Android 同步状态广播只更新当前状态文字，不再重建页面，消除长轮询心跳造成的界面闪烁。
- 词库总览限制在独立的纵向滚动区域，全部、桌面翻译和每个导入词库保持分离的选择卡片。
- 复习卡未显示答案时即可左右滑动：向左记为“忘记”、向右记为“记得”；卡片以横向动画切换，“显示答案”和四个评分按钮仍完整保留。
- 今日计划完成后保留“继续巩固已学内容”入口；该练习轮次不会重复同一张卡，也不会绕过原有间隔复习计划。
